## 논문 핵심 요약
센서 HW 고장 진단 → 잔존 능력 평가(WARN/DEGRADED/FATAL/CRITICAL) → Lanelet2에서 안전 목표 영역 탐색 → 가중치 점수로 MRM 종류·목적지 결정 → Autoware mission/goal planner에 전달.

대상 센서: LiDAR, Camera, GNSS, IMU
고장 유형(HW 계층): sensor dropout / communication loss / driver kill / missed messages / timeout
MRM 종류: emergency stop / comfortable stop / road-shoulder stop / parking-space stop
안전 목표 영역: road shoulder / public parking / right-side road edge / open space

## ④ 가중치 기반 MRM 목적지 선택
- [ ] **후보 수집 노드**: 현재 ego 위치 + Severity 기반 D_max 내의 semantic 영역 모두 추출
- [ ] **스코어링 함수**:
  ```
  score(c) = w1·(1/dist) + w2·observability(c) + w3·map_priority(c) - w4·collision_risk(c)
  ```
  - `dist`: 현재 위치 → 후보 중심까지 path 거리 (lanelet 그래프)
  - `observability`: 살아있는 센서의 FOV에 후보가 들어오는 비율
  - `collision_risk`: 후보 근처 동적 객체 밀도 (잔존 perception 결과 활용)
  - `map_priority`: parking > shoulder > road_edge > open_space (기본값) — 가중치 yaml로 외부화
- [ ] **MRM 종류 매핑**:
  | Severity / 영역 가용 | MRM |
  |---|---|
  | WARN + parking 가능 | parking-space stop |
  | DEGRADED + shoulder | road-shoulder stop |
  | FATAL | comfortable stop (in-lane) |
  | CRITICAL | emergency stop |
- [ ] 출력: `geometry_msgs/PoseStamped` (목표 stop pose) + `mrm_type`

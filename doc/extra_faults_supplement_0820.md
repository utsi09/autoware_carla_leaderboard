# 보조 캠페인: EXTRA 항법 고장 4종 — 본실험 동등 매트릭스 (2026-08-20~21)

본 캠페인(1,131케이스)에 포함되지 않았던 주입기 구현 고장 4종(gm·imb·imd·gb)을
본 캠페인과 **동일한 매트릭스 구조**(교통 3수준 × ours/baseline × 15반복 = 조건·방법당
45케이스)로 실행. v19 논문 통합(표 4-2·5-1·5-2 확장) 및 방어 자료용.

## 설계
- 조건: gm(GNSS Gauss-Markov 상관 편향 σ3m/8m·τ30s), imb(자이로 고정 바이어스
  0.3/1.0 rad/s), imd(자이로 바이어스 램프 0.005/0.02 rad/s²), gb(GNSS 블랙아웃)
- 매트릭스: 7조건 × 방법 2(ours/baseline, 동일 시드 쌍대) × 교통 3(none/def/agg) × 15반복
  = 630케이스. 트리거 t는 케이스 시드 랜덤(10~45s, 주행 기준) — 본 캠페인과 동일 방식
- 총 630 실행 + 인프라 실패 재시도 → 최종 유효 611 / 630 (97%). 잔여 19건은 재시도
  후에도 인프라 실패(케이스 제외 규칙은 본 캠페인과 동일). ours 팔은 7조건 중 5조건이
  n=45 완전 충족(43~45)
- 판정: experiment_runner v2 judge. 보행자 조우 없음 — 감지·대응 수준 실험
- 예정 개명(논문 통합 시): gm→gb(GNSS bias), gb→gf(GNSS fail) — cf/lf/imb 작명 규칙 일치.
  원자료 CSV는 구명칭 유지, 집계에서 매핑

## 관찰
1. **imd 용량-반응**: 램프 기울기에 반비례한 감지 지연 (mid 8.6s vs high 5.4s, 양팔 일관)
   — T_detect(σ) ≤ T_hazard(σ) 정식화의 실측 확장.
2. **gb 지연은 이봉 분포** (양팔 공통): 주행 중 주입(t≤22s) → 중앙 ~3s; 경로상 신호
   대기와 겹치는 주입(t≥23s) → 감지가 재출발 이후로 밀림(~21–40s). 침묵 감쇠의
   speed>1.0 게이트("정차 중 위치 상실은 즉시 위험 아님") 설계의 발현이며, 정차 중
   지연은 위험 노출이 아님. 중앙값 단독 보고는 오도(이봉) — 두 모드 분리 보고 필수.
   ours/baseline 중앙값 차이(25.6 vs 1.9s)는 이봉 혼합비 차이가 만든 허상: 신호등
   위상은 시드로 통제되지 않아 쌍대 케이스도 다른 위상을 만날 수 있음.
3. **정지 방식이 고장 유형을 따라 갈림** (양팔 동일): GNSS 계열(gm·gb) → 컴포트 정지
   위주, IMU 계열(imb·imd) → 전량 이머전시. 부드러운 정차도 궤적 추종이라 회전
   감각(IMU)이 무너지면 Autoware가 급제동으로 강등 — 위임 정지의 등급까지 고장
   유형에 반응.
4. **전 조건 DEFER 수렴**: 항법 고장 → 위치 신뢰 이동 최소치(0.5) 미달 → 이동 포기.
   본문 gn-high(42/45 위임) 패턴의 확장 증거. 이 계열에서 ours와 baseline의 최종
   상태는 동등 — 제안 방식의 이득은 카메라·라이다·gn-mid 계열에서 발생하며,
   여기서는 "나쁠 것 없음"이 확인 사항.

오염 대표로 gn을 선정했습니다. 이후 본 캠페인과 동일한 매트릭스(조건·방법당 45케이스,

100%, 전 케이스가 본문 gn-high와 동일한 정지 위임으로 수렴해 설계 일관성을
확인했습니다."
